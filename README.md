# OS-Helix project page

Static project page for OS-Helix, hosted from the root of the `webpage` branch.

The layout follows the [OS-Symphony `webpage` branch](https://github.com/OS-Copilot/OS-Symphony/tree/webpage): split hero with a right-side illustration, feature list and resource buttons, author byline, abstract and teaser, section tiles, framework, experiments, analysis, case study, and conclusion. Header and tile styles, plus section icons, were adapted from that repository. The original Apache 2.0 license is retained in `OS-SYMPHONY-LICENSE`.

OS-Helix copy, figures, and reported numbers are based on the paper manuscript. The four figures are stored as SVG assets in `assets/`. The hero robot was generated for this project with the built-in image generation tool, using a prompt for a GUI-and-code robot with subtle blue and green double-helix ribbons. The title helix is adapted from [Tabler Icons](https://tabler.io/icons?icon=dna-2) (MIT license in `TABLER-LICENSE`). The three feature icons are from [Lucide](https://lucide.dev/) (ISC license in `LUCIDE-LICENSE`); the arXiv, GitHub, and Hugging Face marks are from [Simple Icons](https://simpleicons.org/) (CC0 license in `SIMPLE-ICONS-LICENSE`).

The Code button links to the OS-Helix GitHub repository. The arXiv and Models & Data buttons are links with empty URLs until public destinations are provided.
