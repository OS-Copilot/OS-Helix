# OS-Helix project page

Static project page for OS-Helix, hosted from the root of the `webpage` branch.

The layout follows the [OS-Symphony `webpage` branch](https://github.com/OS-Copilot/OS-Symphony/tree/webpage): split hero with a right-side illustration, feature list and resource buttons, author byline, overview, framework, experiments, discussion, case studies, and citation. Header and section styles were adapted from that repository. The original Apache 2.0 license is retained in `OS-SYMPHONY-LICENSE`.

OS-Helix copy, figures, and reported numbers are based on the paper manuscript. Seven figures are stored as SVG assets in `assets/`. The hero robot was generated for this project with the built-in image generation tool, using a prompt for a GUI-and-code robot with subtle blue and green double-helix ribbons. The title helix is adapted from [Tabler Icons](https://tabler.io/icons?icon=dna-2) (MIT license in `TABLER-LICENSE`). The three feature icons are from [Lucide](https://lucide.dev/) (ISC license in `LUCIDE-LICENSE`); the arXiv, GitHub, and Hugging Face marks are from [Simple Icons](https://simpleicons.org/) (CC0 license in `SIMPLE-ICONS-LICENSE`).

The Paper button links to the [arXiv paper](https://arxiv.org/abs/2610.22234), and the Code button links to the OS-Helix GitHub repository. The separate Models and Data buttons link to the [Hugging Face model collection](https://huggingface.co/collections/YYangzzzz/os-helix) and [dataset](https://huggingface.co/datasets/YYangzzzz/OS-Helix-Dataset). The training and evaluation code is being organized for release and is coming soon.
